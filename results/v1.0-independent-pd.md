# 9B-PD-01 — Independent PD Handoff Feasibility

[简体中文](v1.0-independent-pd.zh-CN.md)

## Experimental contract

| Item | Definition |
| --- | --- |
| Primary question | Can an RTX 3060 perform part or all of Prefill and then hand the state to an AI Max+ 395 for Decode? |
| Hypothesis | Increasing the accelerator-prefilled share should reduce TTFT and raise Prefill while Decode remains continuous after handoff. |
| Matched control | AI Max+ 395-only, using the same 9B Q6_K model and 5064-input / 128-output request. |
| Changed factor | Prompt tokens prefetched on the RTX 3060 before handoff: none, first 512, first 2048, or full prompt. |
| Primary metrics | Request completion, TTFT, Prefill, Decode, and transferred-state size. |
| Pass boundary | A complete full-PD request with attributable handoff and no material Decode regression inside this run. |
| Does not prove | Simultaneous two-device compute, concurrent service throughput, or transferability to another model/quantization. |

## Measurement boundary

- Model: 9B, Q6_K
- Workload: 5064 input tokens, 128 output tokens
- Measurement: cache disabled; the retained server measurement is the second request
- Devices: RTX 3060 / CUDA Prefill path and AI Max+ 395 / Radeon 8060S / Vulkan Decode path

## Results

| Configuration | Accelerator-prefilled range | TTFT | Prefill | Decode | Handoff |
| --- | --- | ---: | ---: | ---: | ---: |
| AI Max+ 395 only | None | 5.879 s | 861.55 tok/s | 30.24 tok/s | — |
| Partial PD | First 512 tokens | 5.720 s | 886.62 tok/s | 30.22 tok/s | 512 tokens |
| Partial PD | First 2048 tokens | 5.077 s | 999.16 tok/s | 30.18 tok/s | 2048 tokens |
| Full independent PD | Full prompt | **3.496 s** | **1452.29 tok/s** | **30.28 tok/s** | 5063 tokens / 208.57 MiB |

## Answer

The experiment passes its feasibility gate: a full CUDA-Prefill → Vulkan-Decode handoff completed, TTFT and Prefill improved against the matched 395-only request, and Decode stayed within the same narrow band. The two endpoints still run sequential phases, so this record is the prerequisite for—not evidence of—the later concurrent Dense Region.
