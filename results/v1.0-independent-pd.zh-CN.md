# v1.0 — 独立 PD

[English](v1.0-independent-pd.md)

## 目标

让 RTX 3060 作为独立 prefill 计算端，让 Ryzen AI Max+ 395 / Radeon 8060S 作为持有状态并执行 decode 的主端，测量异构状态交接对 TTFT、prefill 与 decode 的影响。

## 测量边界

- 单机 RTX 3060 12GB + Radeon 8060S
- 9B Q6_K
- 输入 5064 token，输出 128 token
- server 请求测量，关闭缓存，保留第二次结果

## 节点数据

| 节点 | RTX 3060 承担范围 | TTFT | Prefill | Decode | 状态交接 |
| --- | ---: | ---: | ---: | ---: | ---: |
| AI Max+ 395 基线 | 0 token | 5.879 s | 861.55 tok/s | 30.24 tok/s | 无 |
| PD-512 | 512 token | 5.720 s | 886.62 tok/s | 30.22 tok/s | 512 token |
| PD-2048 | 2048 token | 5.077 s | 999.16 tok/s | 30.18 tok/s | 2048 token |
| Full PD | 完整 prompt | 3.496 s | 1452.29 tok/s | 30.28 tok/s | 5063 token / 208.57 MiB |

## 观察

完整独立 PD 是 v1.0 最佳节点：相较 AI Max+ 395 基线，TTFT 缩短 2.383 s，prefill 提升 590.74 tok/s，decode 基本不变。两个分段节点显示收益随交接范围增长，但这些结果不能外推到未测试的大模型或长上下文。

## 版本定位

独立 PD 还保留了多请求下 prefill 与 decode 同时工作的架构潜力；v1.0 未对该潜力做并发量化。
