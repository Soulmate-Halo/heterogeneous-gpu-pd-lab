# 9B-PIPE-01 — Asynchronous Layered-PD Dense Acceleration

[简体中文](v2.4-fused-layer-pipeline.zh-CN.md)

## Experimental contract

| Item | Definition |
| --- | --- |
| Primary question | Can the RTX 3060 and AI Max+ 395 both contribute model compute through an asynchronous layered pipeline? |
| Hypothesis | Keeping adjacent micro-batches active on separate layer stages should reduce pipeline bubbles and beat both matched standalone endpoints. |
| Matched controls | RTX 3060-only and AI Max+ 395-only with the same 9B Q6_K, pp5064/tg128 envelope. |
| Fixed factors | Model, quantization, prompt length, output length, and device pair. |
| Changed factor | Pipeline scheduling policy across the v2.1–v2.4 checkpoints. These are refinements inside one experiment, not four experiments. |
| Primary metrics | Prefill, Decode where recorded, run-to-run stability, and the recorded output-correctness boundary. |
| Pass boundary | Final checkpoint exceeds each standalone endpoint on the same recorded Prefill/Decode envelope. |
| Does not prove | General speedup for 27B, MoE, remote-KV, or other quantization/hardware combinations. |

## Mechanism

Model layers remain assigned to their endpoint. RPC events and asynchronous micro-batches allow one stage to work on the next micro-batch while the adjacent stage advances the current one. The Dense Region is this overlap window; the same layer is not computed twice.

## Measurement boundary

| Item | Value |
| --- | --- |
| Model | 9B, Q6_K |
| Workload | pp5064; tg128 where recorded |
| Devices | RTX 3060 12GB / CUDA + AI Max+ 395 / Radeon 8060S / Vulkan |
| Disclosure | Public checkpoint labels; internal layer-allocation ratios withheld |

## Results

Blank cells were not recorded for that checkpoint.

| Node | Role inside this experiment | Prefill | Decode | TTFT |
| --- | --- | ---: | ---: | ---: |
| RTX 3060 control | Standalone CUDA endpoint | 1589.00 tok/s | 43.87 tok/s | — |
| AI Max+ 395 control | Standalone Vulkan endpoint | 970.00 tok/s | 31.27 tok/s | — |
| v2.1 checkpoint | First fused pipeline | 1865.08 tok/s | — | — |
| v2.2 checkpoint | Repeatability/overlap refinement | 1893.87 tok/s | — | — |
| v2.3 checkpoint | Stage-balance refinement | 1999.51 tok/s | 37.16 tok/s | — |
| **v2.4 checkpoint** | Final calibrated pipeline | **2129.69 tok/s** | **50.73 tok/s** | — |

The final Prefill is 34.0% above the RTX 3060 control, 119.6% above the 395 control, and 83.2% of the arithmetic sum of the two standalone Prefill rates. The sum is an efficiency reference, not a claim that standalone rates can simply be added in production.

## Answer and limits

This is the repository’s controlled Dense Acceleration result: both stages contribute useful model compute and the final checkpoint exceeds both matched standalone endpoints. The experiment does not establish the same claim for later 27B KV-only, Ornith, or Flash layer-split records; those have different questions and control quality.
