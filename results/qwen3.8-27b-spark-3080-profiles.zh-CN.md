# 27B-SPARK-01 — Qwen3.8-27B Q4_K_M，RTX 3080 20GB + DGX Spark GB10

[English](qwen3.8-27b-spark-3080-profiles.md)

本文件是本地 3080 + Spark 三档工作档的详档。下面每一行的 Prefill 与 Decode 都来自同一配置、同一负载。2K 与 8K 不拼进同一格。「最高」只表示本次搜索后确认的工作档，不宣称全局最优。组合上的成绩全部是**组合成绩**，不是 3080 单机成绩。

## 实验契约

| 项目 | 定义 |
| --- | --- |
| 要回答的问题 | 在 Qwen3.8-27B Q4_K_M / KV q4_0 上搜完工作点之后，RTX 3080 20GB + DGX Spark GB10 组合能站住的 Prefill、Decode、均衡服务档分别是什么？ |
| 设备 | RTX 3080 20GB 与 DGX Spark GB10 一起算同一个模型。 |
| 模型 / 包络 | Qwen3.8-27B，权重量化 Q4_K_M，KV 缓存 q4_0。 |
| 最高Prefill确认档 | 8192 token 冷输入、128 输出、无投机；系统预热后三次正式测量的中位数，预热轮不计分。 |
| 最高Decode确认档 | 同一套 128 输出微基准，开 DFlash2；2048 与 8192 分行写。 |
| 均衡档 | 8192 token 冷输入、256 输出、DFlash2、六槽服务，并发 C1-C6。 |
| 匹配对照 | 同一模型、量化、KV、输入长度、输出长度下的 RTX 3080 单机。单机上的投机参数按那套系统自己调，和组合不是只改一个变量。 |
| 未记录 | 均衡服务负载下的 3080 单机 C1-C6。 |
| 结论边界 | 最高Prefill确认档的 Prefill 快于本次 3080 单机。不宣称超过所有单机，不替代 395 主机矩阵，不和社区 NVFP4 Spark 成绩排名。 |

## 三档各自牺牲什么

- **最高Prefill确认档。** 8K Prefill 到 **1603.20** tok/s，对照 3080 单机 1113.13（**+44.03%**）。Decode 掉到 **17.62**，对照 33.36。无投机。后来同档 live 复测，8K 三次为 1601.05 / 17.41；不要写成 1700。
- **最高Decode确认档。** 开 DFlash2。2K 组合 1153.95 / 63.97，对照 3080 单机（自己那套 DFlash2 调参）1042.97 / 60.37。8K 组合 1124.32 / 49.20，对照 1015.15 / 58.36。Prefill 远低于 Prefill 确认档。8K 上组合 Decode 没有超过这次 3080 单机；两边投机参数不同。
- **均衡档。** 六槽服务下 C1 到 C6 的 Prefill 停在约 1086-1097 tok/s。聚合 Decode 按整批生成窗口计时，**含其他路还在做 Prefill 的干扰**。它不是 128 输出微基准的单流 Decode，也不是峰值 Decode。没有单机 C1-C6 对照。

搜索阶段出现过 Prefill 1605.21、Decode 67.35。那是搜索样本，不取代上面的确认中位数。

## 主表 — 成对 Prefill / Decode

统计量：除注明外为系统预热后三次正式测量的中位数，预热轮不计分；各次请求使用冷输入，不复用前缀缓存。输出 128。Prefill 确认档无投机；Decode 确认档开 DFlash2。

| 档位 | 负载 | 组合 Prefill（tok/s） | 组合 Decode（tok/s） | 3080 单机 Prefill / Decode |
| --- | --- | ---: | ---: | --- |
| 最高Prefill确认档 | 8192 输入 / 128 输出，无投机 | **1603.20** | 17.62 | 1113.13 / 33.36 |
| 同档后来 live 复测 | 8192 输入 / 128 输出，无投机，三次 | 1601.05 | 17.41 | 同一套 8K 无投机对照 |
| 最高Decode确认档 | 2048 输入 / 128 输出，DFlash2 | 1153.95 | **63.97** | 1042.97 / 60.37 |
| 最高Decode确认档 | 8192 输入 / 128 输出，DFlash2 | 1124.32 | 49.20 | 1015.15 / 58.36 |

live 复测是 Prefill 确认档的再次测量，不是第四档。

## 均衡档 — C1-C6 服务

8192 token 冷输入、DFlash2、六槽服务。每档分别测独立预填充波次和完整请求波次，完整请求输出 256 token。两类波次 × 三轮正式 ×（1+2+3+4+5+6）= 126 个正式请求；36 个正式波次。预热轮不计分，126/126 正式请求成功。表内是三轮正式的分档中位数。

- 聚合 Prefill 来自独立预填充波次：总输入 token /（最后一个首 token 到达 − 最早发起请求），包含少量首 token 生成和请求开销。
- 聚合 Decode 来自完整请求波次：总输出 token /（最晚完成 − 最早首 token 到达），包含同批其他请求尚在 Prefill 的干扰。
- 全程输出、TTFT p95 和整批耗时也来自完整请求波次；全程输出吞吐 = 总输出 token / 整批请求耗时。两类波次的指标按并发档汇总，不是同一批请求的成对阶段速度。
