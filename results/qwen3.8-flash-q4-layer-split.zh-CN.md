# Qwen3.8-Flash Q4 双设备切层 — 3080 + 395 稠密加速

[English](qwen3.8-flash-q4-layer-split.md)

本档记录 v2.14 新增的 r374 Qwen3.8-Flash Q4 双设备切层实验。单个 llama-server 同时运行两个设备：RTX 3080（CUDA0）与 AI Max+ 395（Vulkan1）各自持有层段，微批跨阶段重叠执行。

## 模型与拓扑

| 项目 | 取值 |
| --- | --- |
| 模型 | Qwen3.8-Flash Q4 |
| KV 缓存 | q4_0（K 与 V 均为 q4_0） |
| 引擎 | llama.cpp fork（含上游 [PR #18626](https://github.com/ggml-org/llama.cpp/pull/18626) async/RPC）；单个 llama-server，双设备 |
| 设备 | RTX 3080 20GB（CUDA0）+ AMD Ryzen AI Max+ 395 / Radeon 8060S（Vulkan1） |
| 层切分 | 张量切分 0.38 / 0.62 |
| 批处理 | ubatch 1024、batch 4096、flash attention 开启 |
| 上下文 | 每槽 131072，共 6 槽 |
| 卸载 | 全部层置于 GPU |
| 3080 显存 | 起始 19033 MiB，峰值 19129 MiB（165 次每秒采样） |

## 工作负载

- 6 条互不重复的 prompt，校准到约 2077 输入 token（2074–2082），每条 256 输出 token
- temperature 0，关闭 prompt 缓存，非流式
- C1–C6 六个并发档，每档复用同 6 条 prompt
- 计分前 1 次 C1 预热，不计入结果
- 21/21 计分请求全部 HTTP 200 且 timings 齐全，无异常

指标口径：

- **Prefill 聚合** = 当档各路 prompt token 之和 / 当档各路 prompt 毫秒最大值 × 1000
- **单流 Decode** = 每路 decode 速率（每路 decode 速率 = predicted token / predicted 毫秒 × 1000）的均值
- **聚合 Decode** = 当档各路 predicted token 之和 / 当档各路 predicted 毫秒最大值 × 1000
- **总吞吐** = （prompt 与 predicted token 总和）/ 档墙钟秒

Prefill 在 C4 达到峰值 633.685 tok/s，六档全部保持在 550 tok/s 以上；聚合 Decode 从 C1 的 35.204 增至 C4 的 71.185，六路负载下略有回落。

## 边界

- 约 2077 输入 / 256 输出的口径属于短上下文负载，不得与 27B 或 Ornith 表格排名：模型、硬件角色与口径均不同。
- 3080 显存峰值 19129 MiB，在 20 GB 卡内留有工作集余量。
- 数字逐字取自 r374 完整运行记录，未做任何插值。

数据来源：r374 短上下文 C1–C6 压测完整运行记录（数字逐字取自源记录，未做外推）。
