# V2 实验证据

本目录只放可公开复核的数值和口径，不包含模型权重、PLE 表、主机日志、凭据或私有主机信息。

- `v2-metrics.json` 是发布口径：prefill 三次实测为 `1030.80 / 1163.40 / 1161.10 tok/s`，峰值 `1163.40 tok/s`。
- 聚合解码端到端实测峰值是 C12 的 `60.25 tok/s`（2048 输入、256 输出、12 路、156/156 成功）。
- `240.00 tok/s` 是 N=8 内核批量缩放的 V2 推算目标，状态固定为 `projected_kernel_scaling_target`，不是端到端实测。
- `dflash-prefill-excerpt.json` 是从原始实验件提取的公开数值；原始权重和主机日志不随镜像发布。
